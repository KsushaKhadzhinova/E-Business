## 3. Как запустить VBA

1. Скопировать шаблон из `Материалы\` (например, в новую папку `Excel_NotaCode\`), оригинал не трогать.
2. Открыть копию → если жёлтая плашка «Защищённый просмотр» – «Разрешить редактирование».
3. Alt+F11 → меню File → Import File… → `VBA\NC2_Voronka.bas` (соответствующий модуль, см. ПЛАН.md, шаг 4).
4. Alt+F8 → выбрать `NC2_Voronka.Main` → «Выполнить». Появится сообщение «Готово…».
5. Проверить лист `NotaCode_Итог`; оранжевые ячейки с примечанием «ДОСНЯТЬ» – заполнить самой; примечания «(допущение)» – можно заменить своими значениями.
6. Сохранить как «Книга Excel с поддержкой макросов (*.xlsm)».
7. Если Excel не даёт запускать макросы: Файл → Параметры → Центр управления безопасностью → Параметры макросов (решение принимаешь сама).

Комментарии в `.bas` написаны по-русски в UTF-8: в редакторе VBA они могут выглядеть «кракозябрами» – читать их в VS Code / GitHub. Сам код работает: русские строки в коде записаны транслитом (`R("Respublika Belarus'")`) и превращаются в кириллицу при выполнении.

Важно: макросы проверены статически (синтаксис, объявления переменных, адреса ячеек сверены со структурой шаблонов), но **не запускались на этом компьютере** – доступ к объектной модели VBA из автоматизации был отключён. При первом запуске пройдись по модулю NC1 – если будет ошибка, сообщи строку.

## 5. Что проверить самой в расчётах

- Формула 1: курс и цены 12 / 72 / 120 / 144 BYN.
- Таблица 7: пример S-01 = 28 000 × 0,7 × 0,8 × 0,9 × 0,03 × 72 = 30 482 BYN.
- Формула 15: HHI = 70,6² + 24,0² + 5,2² + 0,2² ≈ 5 588.
- Раздел 2.12: исправления ошибок шаблонов – показать преподавателю «было / стало».
- Итог (таблица 13) – диапазон, а не одно число.
