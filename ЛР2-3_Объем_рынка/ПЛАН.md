## 2. Поисковый спрос (≈ 1 ч, 🔲 сама)

1. Открыть https://wordstat.yandex.ru → войти по Яндекс ID.
2. Регион: «Беларусь» (кнопка «Все регионы» → выбрать Беларусь); устройства: все.
3. Ввести по очереди 10 запросов:
   `idef0 онлайн`, `uml диаграмма онлайн`, `dfd диаграмма онлайн`, `bpmn онлайн редактор`, `er диаграмма онлайн`, `plantuml`, `text to diagram`, `diagram as code`, `idef0 пример курсовая`, `что такое uml`.
   Для каждого записать «Показов в месяц» → лист `Ввод_NotaCode`, ячейки B19:B28.
4. Вкладка «Динамика» → период «по месяцам», последние 12 мес. (10.2025–09.2026) → для каждой группы сложить месячные значения её запросов:
   - Коммерческие: idef0 онлайн + uml диаграмма онлайн + dfd диаграмма онлайн → столбец B;
   - Проблемные: `как нарисовать idef0`, `как построить диаграмму uml` → C;
   - Инструментальные: bpmn онлайн редактор + er диаграмма онлайн + plantuml → D;
   - Учебные/локальные: idef0 пример курсовая + `uml диаграмма минск` → E.
   Кнопка «Скачать» → CSV → `Рисунки/wordstat_<запрос>.csv` (по желанию).
5. Google Trends (по желанию): https://trends.google.com → запросы «uml диаграмма», «idef0» → регион Беларусь → 12 месяцев → скачать CSV «Interest over time» → значения в `03_Google_Trends!D4:E15`.
6. Скриншоты scr_01–scr_03 (см. ИНСТРУКЦИЯ_ДЛЯ_МЕНЯ.md).

## 3. Similarweb (≈ 1 ч, 🔲 сама)

1. https://www.similarweb.com/website/<домен>/ без регистрации. Период – по умолчанию (последние 3 месяца), страна – все.
2. Домены: уже есть plantuml.com, eraser.io, app.diagrams.net, mermaidchart.com (данные в отчёте); добавить `mermaid.live`, `dbdiagram.io`, `lucidchart.com`, `gleek.io`, `d2lang.com`, `structurizr.com`.
3. Для каждого записать: Total Visits, Top Countries (доли РФ и РБ, если видны), Marketing Channels (Direct/Search/Referral/Social/Paid/Display), Bounce rate, Pages/Visit, Avg duration. Особенно – каналы plantuml.com и mermaidchart.com.
4. Скриншот каждой карточки, имя по ЛР3: `Рисунки/scr_05_similarweb_traffic_plantuml_com_world_2026_09.png` и т. д.
5. Внести в Excel: `metodika_ocenki_obema_rynka_po_similarweb.xlsx` лист `02_Конкуренты_SW` (строки 8+), затем повторно запустить макрос и `python nc_model.py` (при изменении – поправить список `SW` в nc_model.py).
