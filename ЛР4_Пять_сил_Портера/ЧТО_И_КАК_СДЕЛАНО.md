# Что и как сделано (ЛР4)

## Кратко

1. Работа старой версии (DiagramCode, `_архив_DiagramCode/labs/lab4-porter`) перенесена на NotaCode и выполнена заново по пунктам трёх методичек. Раздел «Пять сил» состоит из 10 подразделов, есть матрица с доказательствами, карточки 18 конкурентов и журнал источников.
2. Матрица 1/3/5: конкуренция 5, новые участники 3, покупатели 5, поставщики 3, заменители 5, цифровые усилители 3. Среднее — 4,00, высокое давление по порогам 2,0 / 3,5.
3. CR3 = 99,78 %, HHI = 7 590 по реальным данным Similarweb для 4 доменов (из ЛР2-3). Устойчивость вывода проверена в двух дополнительных сценариях: верхняя граница трафика из РФ и только DSL-ниша.
4. Индекс барьеров входа по Excel-шаблону — 3,92, средние барьеры (у верхней границы). Проверен расчётом в Excel через COM.
5. В шаблоне найдены 7 ошибок. Две критичные: **файл не открывался в Excel** (строковая константа длиной 265 символов в 08!A15) и сумма весов 1,04 (без нормирования вывод менялся на «высокие барьеры»).
6. VBA-модуль `LR4_NotaCode.bas` (в кодировке CP1251 для импорта в Excel) заполняет и чинит шаблон, подставляет экспертные баллы там, где нет данных, и строит лист матрицы Портера.
7. Python: радар 5 сил, CR3/HHI по трём сценариям, тепловая карта барьеров с чувствительностью (2,46–5,00).
8. Новые «реальные» цифры не выдумывались. Всё, чего нет в архиве, помечено «🔲 ДОСНЯТЬ» или «(допущение)».

### Принятые решения

- **Угроза новых участников снижена с 5 до 3.** Старая оценка противоречила собственному индексу барьеров. При барьерах 3,92 («средние», у границы высоких) угроза входа не может быть высокой. Запуск дешёвый, но доверие к корректности нотаций и вузовские каналы требуют времени.
- **Цифровые усилители пересчитаны** под NotaCode и методику «выраженность фактора». Среднее 2,33 честно округляется до 3. В старой версии 1,67 было «консервативно» завышено до 3.
- **География.** Доли RU/BY известны только для plantuml.com. Основной расчёт ведётся по глобальному трафику (D = 1,0, допущение), как в ЛР2-3. Сценарий B использует верхние границы доли России, выведенные из списков топ-стран: если России нет в топ-5, её доля меньше доли 5-й страны. CR3 ≥ 99 % при любом варианте.
- **Экспертные баллы вместо нулей.** Если по фактору нет данных, формулы шаблона дают 0 и балл 1, то есть занижают барьер. VBA делает так: пока данных нет, берётся экспертный балл с листа `Ввод_NotaCode`, а колонка J листа 07 показывает источник балла. После досъёма балл автоматически становится расчётным.
- **Веса нормированы пропорционально** (w / 1,04), чтобы не менять структуру методики.
- **Шкалы не смешиваются:** матрица 1/3/5, индекс Excel 1/3/5 с весами, 8 критериев Similarweb 1–5 с диапазонами. Шкала 0–3 не использовалась.
- **Сверка по 8 критериям Similarweb** — 3,88 (высокий). В старой версии было 3,5, критерии пересчитаны для 18 игроков.

### Ошибки шаблона и исправления

1. 08!A15 — константа длиной 265 символов, Excel не открывает файл. Исправленная копия `Excel/shablon_ocenka_barerov_ISPRAVLEN.xlsx` сделана правкой XML с сохранением диаграммы. Та же правка есть в VBA.
2. 01!B8:B10 — формулы сдвинуты на строку.
3. 07 — сумма весов 1,04.
4. 04/05/06 — формулы только в строках 4–8, пустые строки занижали средние.
5. 05!B38 — формула массива (#ЗНАЧ!).
6. 06!B38 — сумма двух долей могла превышать 100 %.
7. 08!D8 — не было интерпретации HHI.

### Проверка

Формулы VBA (04 K/L, 05 L и B38, 06 K и B38, 07 D5–D10, веса) проверены через Excel COM на копии исправленного шаблона. Результат: CR3 = 0,9978, HHI = 7590,4, E13 = 1,00, F13 = 3,92, «средние барьеры». Сам модуль целиком импортировать не удалось: в Excel отключён доступ к объектной модели VBA, а менять настройки безопасности нельзя. При первом запуске `Main` нужно проверить, что он проходит без ошибок.
