## 4. Проверить расчёты

- CR3 = 7 800 000 + 678 500 + 507 000 = 8 985 500; 8 985 500 / 9 005 500 = 0,9978.
- HHI = Σ доля² · 10 000 ≈ 7 590.
- Взвешенная доля Direct = (7 800 000 · 0,6865 + 678 500 · 0,4905) / 9 005 500 = 0,632.
- Сумма весов 1,04 → нормировано к 1,00 (0,1538 / 0,1154 / 0,0769).
- Индекс барьеров = 3,92, «средние барьеры». С весами 1,04 было бы 4,08.
- Среднее пяти сил и цифровых усилителей = 24 / 6 = 4,00 (высокое давление, > 3,5).

## 5. Запуск VBA

1. **Не открывайте шаблон из `Материалы\`** — Excel его не откроет: в 08!A15 строковая константа длиннее 255 символов. Откройте `Excel\shablon_ocenka_barerov_ISPRAVLEN.xlsx`.
2. Файл → Сохранить как → «Книга Excel с поддержкой макросов (*.xlsm)».
3. Alt+F11 → File → Import File → `VBA\LR4_NotaCode.bas`.
4. Alt+F8 → `Main` → Выполнить. Откроется окно с CR3, HHI, суммой весов и индексом.
5. Если макросы заблокированы: Файл → Параметры → Центр управления безопасностью → включить макросы для этого файла или добавить папку в надёжные расположения.
6. Повторный запуск `Main` перезаписывает данные. Сначала сделайте копию с досъёмными значениями.
