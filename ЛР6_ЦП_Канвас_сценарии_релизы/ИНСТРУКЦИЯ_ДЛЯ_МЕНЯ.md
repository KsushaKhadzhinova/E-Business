## 3. Как запустить VBA (каждый из 5 модулей)

1. Скопируйте шаблон из `Материалы\` в папку `VBA\data\` (там лежат `lr6_1.tsv`…`lr6_5.tsv`), откройте копию.
2. Alt+F11 → File → Import File → `VBA\LR6_N_*.bas` (1 — ЦП, 2 — Канвас, 3 — сценарии, 4 — экраны, 5 — релизы).
3. Alt+F8 → `Main` → Выполнить. Если TSV не рядом — макрос откроет диалог выбора файла.
4. Сохраните книгу. Уже заполненные копии (для сверки) — в `Excel_заполненные\` (сделаны скриптом `lr6_fill_excel.py`).
5. Русские комментарии в .bas сохранены в cp1251: при английской локали Windows в редакторе VBA они выглядят «кракозябрами» — на работу не влияет (код — только ASCII, кириллица читается из TSV в UTF-8).
