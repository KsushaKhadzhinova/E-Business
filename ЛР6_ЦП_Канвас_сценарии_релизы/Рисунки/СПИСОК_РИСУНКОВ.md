## Исходники схем (для правки, в отчёт не вставляются)

Карта навигации — генерируется из `Python\lr6_d4_screens.py` (UNITS, NAV). Альтернативная запись mermaid (основной путь P1):

```mermaid
flowchart LR
  U001[U-001 Главная] --> U008[U-008 IDE]
  U001 --> U004[U-004 Тарифы]
  U008 --> U009[U-009 Выбор нотации]
  U008 --> U011[U-011 Problems]
  U011 --> U008
  U008 --> U013[U-013 Сохранение]
  U008 --> U014[U-014 Экспорт]
  U013 --> U019[U-019 Лимит Free]
  U014 --> U019
  U019 --> U004
  U004 --> U008
```

Карта сценариев (journey):

```mermaid
journey
  title S-004 IDEF0 по заданию
  section Настройка
    Шаблон IDEF0: 4: Студент
  section Получение ценности
    DSL и Run: 4: Студент
    Problems: код правила и строка: 3: Студент
    Исправление → OK: 5: Студент
  section Результат
    Save + Export PNG: 5: Студент
```
