## Что исправлено по СТП

- Поля 30/15/20/20 мм, Times New Roman 14, интервал и абзацный отступ 1,25 см, заголовки и подписи таблиц по краям по СТП.
- Титульный лист: «Минск 2026» без месяца.
- Заголовки разделов в тексте прописными (стилем), в содержании обычным регистром; содержание и номера страниц пересчитаны в Word.
- Таблицы: шрифт 12 пт, столбцы по содержимому, пустая строка до подписи и после таблицы, головка повторяется; длинные таблицы режутся на страницы с подписью «Продолжение таблицы N».
- Рисунки: не обрезаются (одинарный интервал), пустые строки до рисунка, подпись по центру.
- Пустая строка перед подразделами.
- Список источников: нумерация по порядку, без тире и курсива, сайты в форме «URL: адрес (дата обращения: дд.мм.гггг)» по образцам ВАК РБ.

## Что сделано после первой версии

- После таблицы или рисунка, за которыми стоит заголовок, подпись другого объекта или конец документа, добавлено предложение по подписи («В таблице N приведено: …», «На рисунке N показано: …»). Предложения формальные: при желании их можно заменить содержательными. В последней сборке формулировка изменена и стала без двоеточия: «Данные по теме «…» приведены в таблице N», «Рисунок N иллюстрирует тему «…»».
- Заголовки разделов прописными и в тексте, и в содержании (решение владелицы).
- Ссылки `[1–3]` убраны в ЛР1, ЛР5 и ЛР7, остальные номера сдвинуты на 3; в ЛР6 убраны ссылки `[6]` и `[7]`, у которых нет записей в списке.
- Запись «Отчеты по лабораторным работам» удалена из списков источников.
- Финальный отчёт ЛР1-7 пересобран по тем же правилам (в нём остаётся отдельный список источников у каждой работы, как в оригинале).
- Отчеты пересобраны текущей версией `report-gen`: заголовки приложений по центру, подпись «Продолжение таблицы» не отрывается от таблицы, таблицы из одной строки заголовка больше не остаются отдельным куском.
- Единственное замечание аудита в финальном отчете: 18 заголовков «ПРИЛОЖЕНИЕ» второго уровня стоят по центру, а правило проверки допускает центр только у заголовков первого уровня. Это замечание самой проверки: приложения по СТП оформляются по центру.

## Что требует решения

- После таблиц и рисунков должен быть текст. В ЛР5 такие абзацы дописаны (14 мест, по данным самих таблиц), в остальных отчётах это только отмечено в аудите (столбец «Аудит»): текст нужно писать или согласовать, как оформлять.
- В ЛР5 в список источников добавлены три методики (записи 1–3) как учебно-методические материалы БГУИР, год 2026: нужны настоящие автор, издатель и год. Запись «Отчёты по лабораторным работам ЛР1–ЛР4» оставлена.
- Заголовки разделов: в содержании обычным регистром (так решено в этой сессии). В другой сессии (ветка `main` проекта report-gen) записано «прописными и в тексте, и в содержании»: нужно выбрать одно.
- Ссылки `[1–3]` в ЛР1, ЛР5 и ЛР7 в тексте не сдвигались и не удалялись.
- Таблицы с обрезанными ячейками («…») и курсивные фразы-заглушки в разделах оставлены как в оригинале.
