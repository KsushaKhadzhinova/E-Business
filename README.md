# Электронный бизнес: лабораторные работы ЛР1–ЛР7 по проекту NotaCode

Репозиторий дисциплины «Электронный бизнес» (БГУИР, ИИТ). Здесь полный цикл бизнес-анализа цифрового продукта, от проверки спроса до решения о запуске.

**Объект анализа — NotaCode**: web-IDE «diagram as code» для UML, BPMN 2.0, ERD, IDEF0/IDEF1X/IDEF3, DFD и сетей Петри. В нём есть собственный DSL, проверка правил нотаций, версии с diff и экспорт в форматы аналогов. Модель — freemium (Free / Pro 4 USD в месяц). Код продукта хранится в отдельных репозиториях. Здесь только бизнес-анализ.

## Сборка финального отчёта

```bash
python Финальный_отчет/build_report.py
```

Скрипт склеивает `ОТЧЕТ.md` всех ЛР, добавляет титульный лист БГУИР и оглавление и сохраняет `Финальный_отчет/ОТЧЕТ_по_лабораторным_работам_1-7_NotaCode.docx` с оформлением: Times New Roman 14, поля 30/15/20/20 мм.
