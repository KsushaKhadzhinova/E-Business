# Электронный Бизнес — курсовые лабораторные работы

Репозиторий по дисциплине «Электронный бизнес»: полный цикл бизнес-анализа цифрового продукта — от проверки спроса до решения о запуске.

## Анализируемый бизнес

В качестве объекта анализа для всех лабораторных (ЛР1–7) используется реальный проект **DiagramCode** (сервис визуального моделирования диаграмм через собственный DSL — UML, ERD, IDEF0/1X/3, DFD, BPMN, сети Петри). Разработка самого продукта ведётся в отдельном приватном репозитории и сюда не включается — здесь только результаты бизнес-анализа по методикам курса.

## Структура репозитория

```
materials/     — исходные материалы курса (методички, презентации, записи лекций) — не редактируются
├── ЛР1/       — спрос: Google Trends, Яндекс Вордстат, семантическое ядро, границы рынка
├── ЛР2/       — оценка объёма рынка (методики через SimilarWeb, воронку, маркетплейсы и т.д.)
├── ЛР3/       — дублирует ЛР2 (подтверждено в чате группы — считать одной работой)
├── ЛР4/       — 5 сил Портера + барьеры входа/выхода через SimilarWeb
├── ЛР5/       — анализ конкурентов по сайтам, уровни конкуренции
├── ЛР6/       — ценностное предложение, Канвас, пользовательские сценарии, страницы/экраны, релизы
├── ЛР7/       — шаблон итогового отчёта (вспомогательный, не обязательный к сдаче отдельно)
├── theory/    — презентации по темам курса
├── lectures/  — записи лекций (экран, по датам)
└── reference/ — вспомогательные материалы (CSS: The Missing Manual — по всей видимости, не по этому курсу, оставлен на всякий случай)

labs/          — выполненные работы по DiagramCode, в двух форматах: .md (рабочая версия) + .docx (по шаблону курса, для сдачи)
├── lab1-demand/
├── lab2-3-market-size/
├── lab4-porter/
├── lab5-competitors/
├── lab6-canvas-releases/
└── lab7-final-report/
```

## Формат сдачи

Все лабораторные сдаются на экзамене единым отчётом (см. методику ЛР7). Здесь `labs/lab7-final-report/` — точка сборки итогового документа из результатов ЛР1–6.
