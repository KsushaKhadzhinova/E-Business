# Электронный Бизнес — курсовые лабораторные работы

Репозиторий по дисциплине «Электронный бизнес»: полный цикл бизнес-анализа цифрового продукта — от проверки спроса до решения о запуске.

## Анализируемый бизнес

В качестве объекта анализа для всех лабораторных (ЛР1–7) используется реальный проект **DiagramCode** (сервис визуального моделирования диаграмм через собственный DSL — UML, ERD, IDEF0/1X/3, DFD, BPMN, сети Петри). Разработка самого продукта ведётся в отдельном приватном репозитории и сюда не включается — здесь только результаты бизнес-анализа по методикам курса.

## Структура репозитория

```
materials/     — исходные материалы курса (методички, презентации, записи лекций) — не редактируются
├── ЛР1/       — спрос: Google Trends, Яндекс Вордстат, семантическое ядро, границы рынка
├── ЛР2/       — оценка объёма рынка (методики через SimilarWeb, воронку, маркетплейсы и т.д.)
├── ЛР3/       — дублирует ЛР2 (подтверждено в чате группы — считать одной работой)
├── ЛР4/       — 5 сил Портера + барьеры входа/выхода через SimilarWeb
├── ЛР5/       — анализ конкурентов по сайтам, уровни конкуренции
├── ЛР6/       — ценностное предложение, Канвас, пользовательские сценарии, страницы/экраны, релизы
├── ЛР7/       — шаблон итогового отчёта (вспомогательный, не обязательный к сдаче отдельно)
├── theory/    — презентации по темам курса
├── lectures/  — записи лекций (экран, по датам)
└── reference/ — вспомогательные материалы (CSS: The Missing Manual — по всей видимости, не по этому курсу, оставлен на всякий случай)

labs/          — выполненные работы по DiagramCode, в двух форматах: .md (рабочая версия) + .docx (по шаблону курса, для сдачи)
├── lab1-demand/
├── lab2-3-market-size/
├── lab4-porter/
├── lab5-competitors/
├── lab6-canvas-releases/
└── lab7-final-report/
```

## Формат сдачи

Все лабораторные сдаются на экзамене единым отчётом (см. методику ЛР7). `labs/lab7-final-report/` содержит готовый сводный документ **«ОТЧЕТ по лабораторным работам №1-7»** — оформлен по стандартному титульному листу БГУИР (по образцу принятых отчётов по другим дисциплинам), 13 разделов, ссылки на полные версии внутри каждой лабораторной.

## Статус выполнения

Все шесть лабораторных проверены независимым «консиллиумом» из трёх агентов-аудиторов (сверка построчно с реальными методичками) и доработаны по результатам проверки — подробности и обоснование каждой правки см. в `ЧТО_И_КАК_СДЕЛАНО.md`.

| Лаба | Статус | Файлы |
|---|---|---|
| ЛР1 (спрос) | Готово + проверено + доработано. Реальные данные Google Trends (тренд, регионы, related queries), Excel-калькулятор тренда/сезонности | `labs/lab1-demand/` |
| ЛР2-3 (объём рынка) | Готово + проверено + доработано. Реальные TAM/SAM/SOM (ВВП Беларуси, SimilarWeb, ПВТ), арифметика сценариев исправлена | `labs/lab2-3-market-size/` |
| ЛР4 (5 сил Портера) | Готово + проверено + доработано. Шкала исправлена на 1/3/5, добавлен SimilarWeb-скоринг барьеров, Excel-файл | `labs/lab4-porter/` |
| ЛР5 (конкуренты) | Готово + проверено + пересобрано. Реальная 8-критериальная формула, модели Левитта и Кано, Excel с живыми формулами | `labs/lab5-competitors/` |
| ЛР6 (Канвас, релизы) | Готово + проверено + доработано. Доход привязан к цифре, добавлены сценарии монетизации/удержания/ошибок, Excel-файл | `labs/lab6-canvas-releases/` |
| ЛР7 (сводный отчёт) | Готово + проверено + доработано. Паспорт, приложения, отдельное краткое резюме, все цифры синхронизированы | `labs/lab7-final-report/` |

**Подробный чеклист по каждой лабе** (что требовала методика / что сделано / что осталось мне / что осталось вам) — в [`ЧЕКЛИСТ_ПО_ЛАБАМ.md`](ЧЕКЛИСТ_ПО_ЛАБАМ.md).

**Что нужно доснять самой** — полный список с инструкциями (включая как занести данные в Excel) в [`ЧТО_ДОСНЯТЬ_САМОЙ.md`](ЧТО_ДОСНЯТЬ_САМОЙ.md): частотность в Яндекс Вордстат (ЛР1, лично проверено — сервис требует входа, обхода нет); ФИО преподавателя на титульном листе; решение по цене подписки; решение по 2 незакрытым семействам сценариев в ЛР6; проверка гипотез на реальных клиентах. Данные SimilarWeb по `eraser.io`/`app.diagrams.net` (ЛР2-3, ЛР4) — уже закрыты, снимать не нужно.

**Как и почему всё сделано** — подробный разбор теории и практики по каждой лабе в [`ЧТО_И_КАК_СДЕЛАНО.md`](ЧТО_И_КАК_СДЕЛАНО.md).
