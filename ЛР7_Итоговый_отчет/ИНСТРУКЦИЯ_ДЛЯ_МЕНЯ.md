## 6. Как запустить VBA (Word)

1. `pandoc ОТЧЕТ.md -o ОТЧЕТ.docx --resource-path=.` (из папки ЛР7). Без pandoc: Word → Файл → Открыть → `ОТЧЕТ.md` → Сохранить как .docx; картинки при этом вставить вручную.
2. Открыть `ОТЧЕТ.docx` → Alt+F11 → File → Import File → `VBA\Оформление_БГУИР.bas`.
3. Закрыть редактор VBA → Alt+F8 → `Main` → «Выполнить» → на вопрос об интервале: «Да» = 1,5, «Нет» = 1,0 (уточните у преподавателя; для отчётов БГУИР обычно 1,0 в таблицах и 1–1,5 в тексте).
4. Макрос выставит поля 30/15/20/20 мм, Times New Roman 14, заголовки, подписи, таблицы 12 пт, номера страниц справа внизу (без номера на титуле) и вставит «СОДЕРЖАНИЕ».
5. Проверить титульный лист вручную (центрирование, «Минск 2026» внизу), обновить оглавление (ПКМ → «Обновить поле» → «целиком»). Сохранить как `.docx`, не `.docm`.
6. Повторить для `КРАТКОЕ_РЕЗЮМЕ.docx`.
