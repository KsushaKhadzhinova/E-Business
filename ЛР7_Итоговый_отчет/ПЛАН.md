## 5. Оформление в Word (≈ 1,5–2 ч)

1. Конвертировать: в папке ЛР7 выполнить `pandoc ОТЧЕТ.md -o ОТЧЕТ.docx --resource-path=.` (так же — `КРАТКОЕ_РЕЗЮМЕ.md`). Если pandoc не установлен — открыть md в Word или скопировать из предпросмотра GitHub.
2. Открыть `ОТЧЕТ.docx` → Alt+F11 → File → Import File → `VBA\Оформление_БГУИР.bas` → Alt+F8 → `Main` → выбрать интервал (1,5 — «Да»; 1,0 — «Нет»).
3. Проверить: титульный лист без номера страницы; «СОДЕРЖАНИЕ» перед первым разделом; заголовки с новой страницы; подписи «Рисунок 7.N — …» по центру; «Таблица N.N — …» слева над таблицей.
4. Если на титуле пропущен номер или стоит лишний разрыв страницы, поправить вручную. Затем ПКМ по оглавлению → «Обновить поле».
5. Сохранить `ОТЧЕТ.docx` и `КРАТКОЕ_РЕЗЮМЕ.docx`.
