## 2. Реконструкция бизнес-моделей ключевых конкурентов (по открытым данным их сайтов)

### PlantUML
- **Ценностное предложение**: бесплатный, открытый, работает офлайн/локально (jar-файл, IDE-плагины), рендеринг прямо в браузере через JS-движок — без сервера, без токенов, без трекинга (цитата с главной страницы: «No server. No tokens. No tracking»).
- **Каналы**: органический поиск, встраивание в IDE (IntelliJ, VS Code), недавно — официальное браузерное расширение для рендера PlantUML прямо внутри GitHub.
- **Монетизация**: отсутствует как продукт — классический open-source проект без прямой выручки.
- **Что стало рыночным стандартом**: поддержка всех классических видов UML (sequence, use case, class, object, activity, component, deployment, state, timing) + нестандартные диаграммы (не-UML) в одном инструменте — это тот минимум охвата нотаций, который аудитория считает нормой.

### Eraser.io
- **Ценностное предложение** (из тарифной страницы, ЛР2-3): «diagram-as-code» + AI-диаграммы + бесконечный канвас + markdown-заметки в одном инструменте, интеграции с GitHub/Notion/Confluence/VS Code.
- **Каналы**: прямые продажи + встроенный продуктовый рост (free-тариф с ограничением в 3 AI-диаграммы — классическая freemium-воронка).
- **Монетизация**: подписка по местам (per-seat): Free $0 → Starter $15-20/мес → Business $45-60/мес → Enterprise по запросу; явное разделение через «кредиты» на AI-диаграммы (3 → 40 → 250 → безлимит) — это конкретная модель ограничения бесплатного тарифа, которую DiagramCode тоже уже применяет (квота 20 AI-запросов/день по умолчанию).
- **Что стало рыночным стандартом (по факту наличия у Eraser.io)**: AI-генерация диаграмм как ключевая продающая фича (не побочная), версионирование файлов (90 дней истории на Starter, безлимит на Business), интеграция с системами разработки как обязательное требование, а не опция.

### Mermaid / MermaidChart
- **Ценностное предложение (open-source ядро)**: DSL-синтаксис диаграмм, рендерящийся прямо в Markdown (GitHub, GitLab, Notion уже поддерживают Mermaid нативно) — самый широкий канал дистрибуции среди всех рассмотренных конкурентов, поскольку не требует установки вообще.
- **Монетизация**: ядро — открытый код, финансируется через GitHub Sponsors (модель донатов ключевым разработчикам, видно на странице «Meet The Team» с кнопками Sponsor); коммерческая надстройка MermaidChart — по данным SimilarWeb (ЛР2-3), заметный трафик из Вьетнама/Индонезии/США, но почти не представлена в целевом для DiagramCode русскоязычном сегменте — **это конкурентный пробел**, который DiagramCode может занять.

## 3. Рыночный стандарт цифрового товара (свод по всем конкурентам)

| Элемент | Стал ли стандартом рынка | У кого впервые/ярче всего замечено |
|---|---|---|
| Текстовый DSL для описания диаграммы | Да, обязательный минимум | PlantUML, Mermaid, D2 |
| Рендер прямо в браузере без установки | Да | PlantUML (JS-движок), Mermaid (нативно в GitHub/Notion) |
| AI-генерация диаграммы по тексту | Становится стандартом (растёт быстрее всего — см. ЛР1) | Eraser.io — явно продающая фича |
| Версионирование/история изменений | Да, у платных продуктов | Eraser.io (90 дней → безлимит по тарифу) |
| Интеграция с GitHub/GitLab/IDE | Да, обязательное требование | PlantUML (расширение для GitHub), Eraser.io (интеграции), Mermaid (нативно в GitHub) |
| Полный охват инженерных нотаций (UML + ERD + IDEF + BPMN + сети Петри в одном инструменте) | **Нет ни у одного конкурента полностью** | — это ниша DiagramCode |
| Совместное редактирование в реальном времени | Частично (не у всех конкурентов явно заявлено) | — |

## 4. Вывод

Рыночный стандарт цифрового товара для категории «диаграмма как код» сегодня — это связка «текстовый DSL + браузерный рендер без установки + интеграция с GitHub-экосистемой», к которой AI-генерация быстро добавляется как новый обязательный элемент (Eraser.io уже сделал её ядром продающего предложения). Ни один из рассмотренных прямых конкурентов не закрывает **весь** набор инженерных нотаций (UML + ERD + IDEF0/1X/3 + DFD + BPMN + сети Петри) в одном продукте — каждый специализируется на 1-2 семействах диаграмм. Это и есть конкурентный пробел, вокруг которого DiagramCode может строить дифференциацию, при этом обязательно закрыв рыночный стандарт (DSL + браузерный рендер + AI + интеграция с git-экосистемой), чтобы не выглядеть неполным по сравнению с Eraser.io.
