## 5. Расчёт «сверху вниз» (top-down)

```
Объём рынка = ПВТ-компании × доля с трафиком/интересом к diagram-as-code × доля готовых платить × средний чек/год
            = 1000 × 0,30 (допущение: доля компаний, чьи команды уже искали/использовали diagram-as-code инструменты,
                            ориентир — доля России в трафике plantuml.com среди стран-лидеров ~9%, для Беларуси как
                            более узкого IT-хаба берём выше — 30%, допущение на проверку)
            × 0,15 (доля готовых платить за AI-надстройку, а не остаться на бесплatном PlantUML/Mermaid — допущение)
            × $480/год
            = 1000 × 0,30 × 0,15 × 480 ≈ $21 600/год (верхняя ориентировочная оценка для сегмента ПВТ Беларуси)
```

## 6. Расчёт «снизу вверх» (bottom-up) — через количество потенциальных клиентов

```
Платежеспособный рынок = число компаний в сегменте × доля нуждающихся × доля готовых покупать онлайн × средний годовой чек
                        = 1000 × 0,60 (допущение: доля компаний, ведущих техдокументацию с диаграммами)
                          × 0,10 (доля готовых платить именно за AI-инструмент, а не бесплатную альтернативу)
                          × $480
                        = 1000 × 0,60 × 0,10 × 480 = $28 800/год
```

Оба метода («сверху вниз» и «снизу вверх») дают близкий порядок величины ($21,6К - $28,8К/год для стартового сегмента ПВТ Беларуси) — это хороший признак согласованности расчёта по правилам методики (раздел 11 инструкции ЛР2: «если методики сильно расходятся — проверить коэффициенты сужения»).

## 7. Оценка через цифровую воронку

```
Выручка = охват (посетители блога/документации DiagramCode + органический поиск по семантическому ядру ЛР1)
        × доля переходов на сайт (допущение 20%)
        × конверсия в регистрацию (допущение 8%, ориентир по индустрии для dev-tools)
        × конверсия в оплату (допущение 5%, консервативно из-за сильных бесплатных альтернатив — PlantUML/Mermaid бесплатны)
        × средний чек $480/год
```

Без готового трафика сайта DiagramCode (продукт ещё не запущен) этот расчёт пока не даёт числа — он используется после первого релиза как инструмент проверки факта, а не прогноза (см. общий принцип методики: воронка — расчёт по фактическим данным, а не по гипотетическому трафику).

## 10. Итоговый вывод

Рынок был определён как русскоязычные IT-компании (стартовая база — зарегистрированные в ПВТ Беларуси, более 1000 компаний), которым нужен DSL-инструмент для диаграмм с AI-генерацией. Поисковый спрос (ЛР1) и данные SimilarWeb по ближайшему прямому аналогу (plantuml.com, Россия — топ-страна трафика) подтверждают наличие цифровой активности в сегменте. Расчёт «сверху вниз» и «снизу вверх» дают согласованный диапазон **$15 000–29 000/год** в базовом и осторожном сценарии для стартового сегмента ПВТ Беларуси, с потенциалом кратного роста при расширении на СНГ (оптимистичный сценарий). Расчёт требует дальнейшей проверки через прямой опрос потенциальных клиентов и тестовые продажи после запуска первого релиза.

## 11. Ограничения

- SimilarWeb на бесплатном тарифе дал полные данные только по 2 доменам из 4 запланированных (eraser.io и app.diagrams.net — «лимит запросов исчерпан»); эти два — важные конкуренты, для полной картины нужен платный доступ или запрос в другой день/с другого аккаунта.
- Трафик сайта plantuml.com системно недооценивает реальную базу пользователей (локальный рендеринг через IDE-плагины не отслеживается веб-аналитикой).
- Все коэффициенты сужения (доля нуждающихся, доля готовых платить, конверсии) — экспертные допущения, а не измеренные величины; помечены явно и подлежат проверке.
- Цена DiagramCode ($8/участник/мес) — рабочее допущение по аналогии с рынком, не подтверждённое решение о прайсинге.
