## 5. Как запустить VBA

1. Скопировать `Материалы/shablon_excel_ocenka_trenda_sezonnosti_delovyh_ciklov_google_trends_wordstat.xlsx` в папку ЛР1 и открыть копию.
2. Файл → Сохранить как → «Книга Excel с поддержкой макросов (*.xlsm)», например `ЛР1_Тренд_Сезонность_NotaCode.xlsm`.
3. Alt+F11 → File → Import File… → `VBA\LR1_NotaCode_Trend.bas`.
4. Alt+F8 → `Main` → Выполнить. Архивный xlsx ищется автоматически (папка книги, `..\_архив_DiagramCode\…`, абсолютный путь). Если файл не найден, откроется окно выбора; «Отмена» — взять данные с листа «Ввод_NotaCode».
5. Если кириллица в редакторе VBA отображается «кракозябрами», в Windows должна быть русская кодировка для программ без Юникода. Файл .bas сохранён в Windows-1251.
6. Дополнительно: `ApplyCenteredMA` — поправка тренда (центрированная MA), `RestoreTemplateMA` — возврат исходных формул.
