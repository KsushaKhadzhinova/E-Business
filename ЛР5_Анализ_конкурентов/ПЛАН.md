# ЛР5. План выполнения (NotaCode)

Общее время: ≈ 9–11 ч (из них ≈ 3–4 ч — сбор недостающих данных на сайтах; остальное уже подготовлено).

## 0. Порядок чтения материалов (≈ 1 ч)

1. `ЗАДАНИЕ.md` — разделы 1, 4, 14 (что сдаётся, шаги, чек-лист).
2. `Материалы/Методика_классификации_компаний_по_уровням_конкуренции.docx` → затем шаблон классификации (листы 00, 03, 05).
3. `Материалы/Методика_анализа_конкурентов_по_сайтам_цифровой_товар.docx` → шаблон Левитт–Кано (00, 99 — описание моделей только там).
4. `Материалы/Методика_анализа_бизнес_модели_конкурентов_по_сайтам.docx` → шаблон бизнес-модели (01, 13).
5. `ОТЧЕТ.md` — готовый текст, сверить с методичками.

## 1. Подготовка (≈ 20 мин)

1. Создать папку `Рисунки/` (есть), открыть `ИНСТРУКЦИЯ_ДЛЯ_МЕНЯ.md` — там список скриншотов.
2. Скопировать 3 шаблона из `Материалы/` в корень папки ЛР5 и сохранить как `.xlsm`:
   `ЛР5_1_Классификация_NotaCode.xlsm`, `ЛР5_2_Левитт_Кано_NotaCode.xlsm`, `ЛР5_3_Бизнес_модель_NotaCode.xlsm`.
   (Готовые проверочные копии, заполненные через Python + Excel, лежат в `Excel/*.xlsx`.)

## 2. Часть A — классификация (≈ 2,5 ч)

1. Поиск (≈ 40 мин). Браузер в режиме инкогнито, регион — Беларусь. Запросы:
   `diagram as code`, `text to diagram`, `uml онлайн`, `plantuml online`, `построить idef0 онлайн`, `dfd диаграмма онлайн`,
   `er диаграмма онлайн`, `bpmn редактор онлайн`, `диаграмма для курсовой`, `plantuml alternatives`, `mermaid vs d2`.
   Для каждого запроса зафиксировать: какие из K001–K020 в топ-10 и в рекламе; новые компании → добавить в `01_Компании` (K021+).
   Скриншот выдачи 2 запросов → `Рисунки/scr_01_vydacha_uml_online.png`, `scr_02_vydacha_idef0.png`.
2. Импорт VBA: открыть `ЛР5_1_...xlsm` → Alt+F11 → File → Import File → `VBA/LR5_1_Klassifikaciya.bas` → Alt+F8 → `Main`.
3. Проверить листы: 04_Оценка (N, O, P, R), 06_Сводка (топ-10, вывод A30), 07_Карта (диаграмма).
4. Досбор фактов по компаниям со статусом «Требует уточнения» (K006, K008, K012, K013, K014): сайт → главная, тарифы; внести строки в `02_Доказательства`, при необходимости поправить баллы C5/C7 в `04_Оценка`, перезапустить `Main` (или только пересчёт F9).
5. Скриншот листа 04_Оценка и 07_Карта → `scr_03_ocenka.png`, `scr_04_karta_excel.png`.

## 3. Часть B — цифровой товар (≈ 3 ч)

1. Импорт `VBA/LR5_2_LevittKano.bas` в `ЛР5_2_...xlsm`, запуск `Main`.
2. Пройти сайты C01–C12 по единой карте страниц (главная → товар → тарифы → демо/редактор → документация → правовые):
   открыть URL из `02_Карта_сайтов`, вписать дату (столбец G), снять скриншот с именем из столбца H, заменить «🔲 URL …» на точный URL.
3. В `04_Кано` проверить признаки со знаком «?» (столбец D) — оставить/убрать конкурента, поправить G.
4. В `06_Сравнение` пересмотреть баллы Gleek (I), dbdiagram (J), Ramus (L) после просмотра сайтов.
5. Проверить `09_Дашборд`: конкурентов 12, страниц ≥ 30, признаков Левитта ≥ 40, требований Кано ≥ 25.
6. Скриншот дашборда → `scr_39_dashboard_lk.png`.

## 4. Часть C — бизнес-модель (≈ 2 ч)

1. Импорт `VBA/LR5_3_BiznesModel.bas` в `ЛР5_3_...xlsm`, запуск `Main` (снимет объединение A2:Q2 и задаст веса).
2. Досбор по C05 Gleek, C08 Ramus, C09 Lucidchart: тарифы, регистрация, вакансии → новые строки `03_Факты_сайта` (F030+).
3. Когда полнота ≥ 0,85 и доказательность ≥ 3 — сменить статус на «завершен» в `02_Конкуренты`.
4. Проверить `12_Сводка`: рейтинг, классификация практик; выводы в C23:C27.
5. Скриншот `09_Матрица` и `12_Сводка` → `scr_40_bm_matrica.png`, `scr_41_bm_svodka.png`.

## 5. Python и рисунки (≈ 15 мин)

```
cd Python
python -B lr5_calc.py            # расчёты и CSV в results/
python -B export_vba_data.py     # если меняли lr5_data.py — пересоздать TSV для VBA
python -B lr5_charts.py          # 7 PNG в ../Рисунки
python -B fill_templates_excel.py  # (необязательно) заполнить копии в ../Excel и сверить формулы
```

## 6. Отчёт (≈ 1 ч)

1. Заменить в `ОТЧЕТ.md` все «🔲» на снятые данные; обновить таблицы, если менялись баллы.
2. Вставить скриншоты (по желанию — в приложение), собрать docx сборщиком `_tools/build_lab_docx.py`.
3. Пройти `ЧЕКЛИСТ.md`.
