# ЛР5. Что сделать самой

## 1. Запуск VBA (для каждого из трёх шаблонов)

1. Скопировать шаблон из `Материалы/` в корень папки `ЛР5_Анализ_конкурентов` и «Сохранить как» → «Книга Excel с поддержкой макросов (.xlsm)».
2. Рядом должна лежать папка `VBA/data` (TSV-файлы) — макрос найдёт её сам, иначе спросит папку.
3. Alt+F11 → File → Import File → нужный `.bas`:
   - классификация → `VBA/LR5_1_Klassifikaciya.bas`;
   - Левитт–Кано → `VBA/LR5_2_LevittKano.bas`;
   - бизнес-модель → `VBA/LR5_3_BiznesModel.bas`.
4. Alt+F8 → `Main` → Выполнить. В конце появится сообщение «Готово: …».
5. Если комментарии в редакторе VBA — «кракозябры», это нормально (кодировка), код только ASCII.
6. Если в листах вместо имён пусто — у вас Excel без XLOOKUP; модуль 1 сам заменяет XLOOKUP на ИНДЕКС/ПОИСКПОЗ.

Меняли данные? Правьте `Python/lr5_data.py` → `python -B export_vba_data.py` → повторно `Main`. Либо правьте прямо в Excel.
